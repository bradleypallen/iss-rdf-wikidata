# Data

The subset of Wikidata that the pipeline runs on. Nothing is here yet.

Every file placed here must be traceable to the run that produced it: either it is a copy
of a body in `results/`, or it is built from such bodies by a script in this repository.
The subset must be closed for the entries: every triple that an entry's premises, defeaters
or guards can read is in it.

Wikidata's structured data is in the public domain under CC0 1.0.
